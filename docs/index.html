Grid Load Forecasting Index

How well do time-series foundation models forecast US electricity demand with no training on it? A versioned leaderboard over 49 balancing authorities, scored against simple baselines and each grid operator's own day-ahead forecast.

Live track

Live track starts on publication

On the live track, a forecast for each balancing authority is committed to the repository before the day it forecasts begins — the commit time is the proof. No model can have seen the answer, so contamination is impossible by construction, and every model is ranked, whenever it was released. Forecasts are scored against the demand values as published seven days after the target day.

How to read this

Skill % is the headline number. It says how much lower a model's error is than the seasonal-naive guess (the demand at the same hour last week), combined across every authority and issue day. 0% means no better than that simple guess; a negative score means worse. Higher is better.

95% interval is the range the skill score plausibly falls in, from a paired bootstrap over authorities and issue days. It describes one model on its own: two models whose intervals overlap may still be clearly different, and two whose intervals do not overlap are not automatically ordered. Whether one model actually beats another is judged from the paired differences in "Which differences are real" above.

Beats seasonal naive is the share of individual forecast windows in which the model's error was lower than seasonal naive's. (It is not fev-bench's "win rate", which averages wins against every other model; that figure is in the score files as avg_win_rate.)

MASE is the average absolute error, scaled by how hard the series is to forecast with a one-week seasonal guess. Below 1 means the model beat that yardstick on average; it is an error, so lower is better.

Coverage (80%) checks the model's own uncertainty ranges: the actual demand should land inside its 80% interval about 80% of the time. Much lower means the model is overconfident. Models that publish no intervals show a dash. Sundial's intervals are the empirical ranges of 20 generated samples, exactly as the model ships them — its low coverage was checked against the model's own quick-start code and is a property of the model, not of this harness.

Beats operator is the share of days on which the model's day-ahead error was lower than the grid operator's own published day-ahead forecast — the number a model would have to beat to be useful in operations. Day-ahead only.

Failed windows counts forecast windows a run failed to produce. By the index's failure rule, a failed window takes the seasonal-naive score, so a failure can never flatter a model.

Released during window would mark a model released after the retrospective window started (3 November 2025). It might in principle have trained on part of the test data, so it would be scored and shown, but excluded from the retrospective headline ranking; on the live track its forecasts are made before the data exists, so it would rank normally there. No model in this release carries the mark: every model's first public weights predate the window.
